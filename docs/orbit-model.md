# ORBIT 軌道實驗室

入口：`apps/orbit/index.html`。可直接由靜態伺服器或 GitHub Pages 提供，無需建置或外部程式庫。

## 操作

預設介面維持高一學生的基本觀察：拖曳發射、暫停、預測軌道、量測方格及簡單的 F = GMm/r² 說明。參考 `planetary-orbit-simulation2.html` 的軌跡與外觀操作，新增預設收起的「進階操作」：可只清除走過的軌跡、選擇保留長度，以及設定新星體的顯示大小／顏色。這些設定不改變初始位置、速度、引力、碰撞半徑或時間；範例維持各軌道既有配色。既有星體保持建立時的大小與顏色。

- 在地球表面以外按下，位置就是星體的初始位置；拖曳箭頭表示初速度，放開才建立星體。
- 每 30 CSS px 的箭頭長度代表 1 km/s，方向與拖曳方向相同。拖曳靈敏度為初版的三分之一，便於在束縛軌道範圍微調初速。視野縮放不改變這個速度比例。單擊等於零初速，不自動補上切向速度。
- 四個範例從同一個 `r = 3.4 R⊕` 位置，以逆時針切線方向分別給 `v圓`、`0.8 v圓`、`√2 v圓`、`1.6 v圓`。
- 支援滑鼠、觸控與鍵盤。Canvas 聚焦後：方向鍵調整起點；Shift＋方向鍵調整速度；Enter 開始設定或發射；Escape 取消。暫停時可建立星體並在同一時刻開始比較。
- 星體飛出視野仍繼續求解，邊緣箭頭標示方向，可縮小視野觀察。選單可選擇每顆星體；支援個別移除及全部清空。
- 預設顯示以球心為原點的量測方格，可勾選開關。刻度單位為地球半徑 R⊕，下方同時標示每格的 km 距離；縮放時採用 0.25、0.5、1、2、5 等間距，保持每格至少約 24–30 CSS px，手機也能保留足夠的量測格數。方格與星體位置使用相同的實體距離尺度。
- 觀測欄顯示近點、遠點與 `a = (r近 + r遠)/2`，a 即橢圓半長軸；這是兩個極值的平均，不是時間平均距離。徑向與逃逸運動不顯示平均軌道半徑。會撞擊的橢圓註明這些是理論軌道值，實際運動仍在球面停止。

## 物理與單位

採用固定、球對稱地球，半徑 `R = 6371 km`，重力參數 `μ = GM = 398600.4418 km³/s²`。各星體為獨立質點：

`d²r/dt² = −μ r / |r|³`

沒有星體之間的引力或碰撞，也沒有中心星球的反作用移動。限制為二維平面，忽略大氣、其他天體、扁率與相對論。這是所述理想化假設下的牛頓引力問題，而非完整真實地球環境。

`physics.js` 使用通用變數克卜勒方程與 Lagrange f、g 係數，從不可變的發射狀態求出每個時刻的位置和速度。Stumpff 函數在近零使用級數，其他位置採三角／雙曲函數。以帶括區保護的 Newton 迭代求解通用異常量，時間方程相對殘差目標 `2×10⁻¹²`，不累加 Euler 步進誤差。橢圓完整週期先取模，雙曲線用對數初猜避免長時間求解時的指數溢位。

軌道分類與顯示量：

- 比機械能 `ε = |v|²/2 − μ/r`，單位 `km²/s²`；角動量 `h = x vy − y vx`。
- 偏心率向量 `e = ((|v|² − μ/r) r − (r·v) v)/μ`。
- `ε < 0` 是束縛軌道；`ε = 0` 是臨界逃逸；`ε > 0` 是非束縛軌道。零角動量另標為徑向運動，避免把直線軌跡標成一般圓錐曲線。
- 圓軌道速度 `√(μ/r)`；逃逸速度 `√(2μ/r)`。近拋物線判斷採 `|αr| < 10⁻¹²`（`α = −2ε/μ`），僅用於分類與撞擊極限公式，傳播保留實際 α。

## 撞擊與繪圖

由軌道和 `r = R` 的第一個未來交點求出撞擊時間：橢圓使用偏近點角，雙曲線使用雙曲近點角，拋物線使用 Barker 方程；徑向拋物線使用自由落下的解析時間。演算在該時刻停止，因此不會因動畫影格跨過球面而漏掉擦邊撞擊。零初速、先向外再落回和高速向內的徑向情境也適用。

虛線為相同引力模型的未來位置，最多預測一個週期、首次撞擊或七天；採近球面較密的取樣。實線記錄已走過的位置，最多保留 2400 個點。這些折線只用於畫圖，不是積分步驟；放大、縮小及勾選預測都不改變物理。

動畫提供 60×、600×、1800×、3600×、7200×；長時間卡頓的單影格壁鐘增量上限 50 ms，避免恢復時突然跳躍，慢速裝置實際播放可能低於標示倍率。背景分頁暫停，回到分頁後不追趕背景時間。尊重減少動態設定，介面沒有額外裝飾動畫；實驗本身可用暫停按鈕停止。

## 驗證

執行 `node --test tests/orbit.test.js`：涵蓋圓軌道 1000 圈後的解析位置、橢圓近遠點、Barker 拋物線、雙曲近點角解、能量和角動量守恆、精確表面撞擊、視野外重力、各星體獨立性及無效輸入。

`tests/orbit.browser.test.cjs` 使用 Playwright：檢查拖曳兩倍距離得兩倍初速、發射起點固定、暫停與縮放、取消、鍵盤、四種範例、零初速落下、觸控，以及 320/390/768/1024/1440 CSS px 的 DOM、文字、幾何和截圖。設定 `ORBIT_LAYOUT_AUDIT` 可使用 web-layout-qa 的原版瀏覽器審核函數；`NODE_PATH` 與 `PLAYWRIGHT_CHROMIUM_EXECUTABLE` 可指定既有 Playwright 和 Chromium。預設伺服器為 `http://127.0.0.1:4179`，亦可用 `ORBIT_TEST_URL` 覆寫。

參考：

- [Wisdom & Hernandez, A Fast and Accurate Universal Kepler Solver without Stumpff Series](https://arxiv.org/abs/1508.02699)：通用變數初值問題與 f、g 表述；本實作使用傳統 Stumpff 形式，未聲稱複製該論文的最佳化程式。
- [NASA, Flight to Mars: Calculations](https://cdaweb.gsfc.nasa.gov/pub/documents/archived_websites/pwg.gsfc.nasa.gov/stargaze/Smars2.htm)：軌道能量符號及逃逸速度關係。
