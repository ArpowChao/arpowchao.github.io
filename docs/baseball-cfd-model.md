# 棒球氣流實驗室：數值模型

入口：`apps/baseball-cfd/index.html`。這是用於探索流體與縫線幾何的二維 CFD 教學模型。

## 求解方式

- D2Q9、單鬆弛時間 BGK 格子玻爾茲曼法。每格九個分布，執行碰撞、pull streaming 和反彈邊界；沒有預先繪製的速度場、縫線力倍率或人工尾流。
- 預設每側 288 × 144 格，圓形直徑 44 格。兩側各自求解；幾何之外的參數、邊界及初始分布相同。
- 格子來流 `U = 0.055`，黏度 `ν = U D / Re`，`τ = 0.5 + 3ν`。模型 Re 可設為 60–160。此範圍與低格子速度兼顧即時效能及穩定性。
- 左側、上側與下側指定均勻平衡分布；右側採零梯度開放出流。這是有限計算域，邊界距離及出流近似會影響結果。
- 圓體和縫線凸起採 halfway bounce-back。旋轉以 `S = ωR / U` 設定表面速度。縫線方位固定；各反彈連結使用局部幾何法向，將壁速投影到切線以避免固定凸起產生法向壁速。
- Worker 以短批次持續演算並傳回獨立複製的可轉移陣列。暫停、24 步步進和參數重設可中斷連續演算。世代編號排除滑桿快速操作的舊結果。背景分頁暫停運算，恢復可見時依使用者選擇繼續。

## 幾何與尺度

真球參考直徑為 73 mm，空氣運動黏度取 `1.5 × 10⁻⁵ m²/s`。速度 80–160 km/h 對應真球參考 Re 約 `1.08–2.16 × 10⁵`，與數值模型 Re 分開顯示。

縫線以 2 或 4 個等角度圓形凸起近似，並非二縫線／四縫線握法。輸入的參考高度 0–1.5 mm 放大 6 倍，轉換為格點：`h格 = h毫米 × 6 × 44 / 73`。障礙物會離散為格點；低於一格的高度與小角度變更可能有階梯狀反應。設為 0 時，兩側數值解完全相同。

固定模型 Re 時，球速不改變光滑無旋轉的無因次流場；它改變旋轉比與實體時間映射。這是刻意採用的尺度分離，介面有說明。

二維圓形截面在流體力學上代表長圓柱。模型未解析三維球體、皮革粗糙度、移動縫線、真球高 Re 邊界層轉捩或湍流。因此結果不能用於投球軌跡、真實棒球受力或縫線偏移尾流（SSW）的定量預測。

## 圖表與輸出

- 流速色彩：`|u| / U`，0–2，超過上限時顏色飽和。
- 壓力係數：LBM 中 `p = ρ/3`，因此 `Cp = 2(ρ−1)/(3U²)`，參考密度取來流 1。色彩 −4 至 +4，兩端標示飽和範圍。
- 渦度：畫面座標 `∂uy/∂x − ∂ux/∂y`，以 `D/U` 無因次化。y 向下，正值表示畫面上的順時針。靠牆使用流體格點單邊差分，其他格點使用中央差分。
- 流線由當下求解速度場以雙線性取樣及中點步進取得，不代表非定常流中的粒子歷史軌跡。
- 周邊 Cp 曲線沿各自幾何表面外約 2 格取樣，每 5° 一點。角度從球右方開始逆時針增加；凸起輪廓由中央圓及縫線圓的聯集求得。
- 尾流差異：在球心下游約 0.6–3.5 個球徑、中心線上下各 1 個球徑，排除任一側固體的共同流體格點，計算 `sqrt(mean(|u有縫線−u光滑|²)) / U`。這是瞬時速度差，不是力或球路。
- CSV 同時輸出兩側完整格點、固體遮罩、格子速度、密度、Cp 及格子渦度，附當下條件與步數。固體速度是指定剛體參考速度，固體內 Cp／渦度不是流體量；流場分析須排除 `solid = 1`。
- 模型從均勻來流開始，最初的壓力波和未發展尾流不是穩態。介面顯示演算步數及無因次對流時間 `tU/D`，沒有宣稱自動收斂。

## 驗證

`node --test tests/baseball-cfd.test.js` 檢查零縫線對照、幾何與實際尾流差異、旋轉反向、壓力及渦度計算、極端參數穩定性、傳輸陣列及 Worker 的世代／暫停／步進。

`tests/baseball-cfd.browser.test.cjs` 驗證瀏覽器控制、重設、CSV、流場模式及窄螢幕版面。需可用的 Playwright 和本機 HTTP server。這些是數值及互動回歸檢查，並非與真實棒球風洞結果的驗證。
