# 棒球氣流實驗室：數值模型

入口：`apps/baseball-cfd/index.html`。這是用於探索流體、旋轉與縫線幾何的二維 CFD 教學模型。

## 求解方式

- D2Q9 格子玻爾茲曼法，採雙鬆弛時間（TRT，magic Λ = 3/16）碰撞。每格九個分布，執行碰撞、push streaming 和反彈邊界；沒有預先繪製的速度場、縫線力倍率或人工尾流。
- 預設每側 320 × 161 格，圓形直徑 D = 24 格。球心距入口 3.5 D、距出口約 9.8 D；高度 6.7 D，阻塞比約 15%。
- 格子來流 `U = 0.1`，黏度 `ν = U D / Re`，`τ = 0.5 + 3ν`。
- 左側為速度入口，前 0.75 D 設吸收層，避免壓力波在入口和球之間來回反射。上下為自由滑移（鏡面反射）邊界；右側為零梯度出流。
- 初始條件為理想（勢流）繞圓流場，免去突然起動產生的壓力衝擊；尾流中另放一個很弱、無散度的小渦旋（兩側相同），讓卡門渦街在幾個球徑內出現。
- 圓體和縫線凸起採 halfway bounce-back。旋轉以 `S = ωR / V` 設定表面切向速度；縫線方位固定，各連結只保留壁速的切向分量。

## 球速與雷諾數

真球 Re 約 10⁵，二維即時模擬無法解析。球速滑桿依比例對應到模型 Re：80 km/h → 60、160 km/h → 180（線性）。旋轉比 S 依真實球速與轉速計算。真球參考 Re 另外顯示，不參與求解。

## 力與壓力

- 球受的力由每條邊界連結的動量交換加總：`F = Σ c_q (f_q^post + f_q̄^new)`。`C_D = F_x / (½ρU²D)`，`C_L = −F_y / (½ρU²D)`（畫面 y 向下，所以 C_L 正值表示向上）。
- 平均只取完整的渦旋脫落週期：以濾除聲波雜訊後的升力訊號偵測每個週期，略過起動後的第一個週期。沒有渦旋脫落（穩定流）時，累積 12 個球徑後改用一般時間平均。這樣光滑、不旋轉的球平均升力約為 0，而不會因為只算到半個週期而偏向一側。
- 壓力係數 `Cp = 2(ρ − ρ∞)/(3U²)`，ρ∞ 為球前方約 2.6 D 整列格點的實測平均密度。正前方停滯點 Cp ≈ 1.0–1.1。
- 時間平均的速度與壓力場在 4 個球徑後開始每 5 步累積。

## 驗證（節錄，Re 135，D = 24）

| 情況 | 平均 C_L | 平均 C_D |
|---|---|---|
| 光滑、不旋轉 | ≈ 0.00 | 約 1.6 |
| 後旋 1800 rpm（S = −0.19） | +0.47 | 約 1.6 |
| 上旋 1800 rpm（S = +0.19） | −0.47 | 約 1.6 |
| 單側縫線（95°、1.5 mm × 6） | −0.34 | 約 2.1 |

渦旋脫落 Strouhal 數約 0.18–0.22（含 15% 阻塞效應）。阻力係數比無界圓柱略高，是有限風洞阻塞的結果。

## 顯示

- 煙線（預設）：從球前方 2 D 的噴嘴排連續釋放被動示蹤點，以目前求解的速度場推進（中點法），呈現煙霧風洞中看到的條紋線（streakline）。播放速率跟隨實際演算步數。
- 流速、壓力、渦度色圖，可切換時間平均（流速、壓力）。流線為瞬時速度場的流線。
- 力的箭頭：黃色為升力、淺色為阻力；有完整週期平均時顯示平均值，否則顯示平滑後的瞬時值並標示「瞬時」。

## 限制

二維圓形截面在流體力學上代表長圓柱。模型未解析三維球體、皮革粗糙度、移動縫線、真球高 Re 邊界層轉捩或湍流。力的方向可以定性對照馬格努斯效應與縫線偏移尾流（SSW），數值不能用於預測投球軌跡或真實受力。
