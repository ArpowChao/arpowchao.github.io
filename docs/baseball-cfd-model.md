# 棒球氣流實驗室：3D 縫線與球路

入口：`apps/baseball-cfd/index.html`。本頁已由二維 LBM 截面風洞改為三維球面邊界層與投球軌跡教學模型；入口網址維持不變。

## 執行方式

所有數值計算均在瀏覽器 JavaScript 執行，主要工作交由 Web Worker；靜態網站只提供 HTML 與 JS 檔案，不需要 Python、後端 API 或外部 CDN。Three.js 與授權檔案放在同目錄的 `lib/`。

- `flow_tables.js`：每次啟動用 RK4 射擊法建立 Falkner–Skan 速度剖面，並積分軸對稱 Thwaites 模板。沒有載入 Python 產生的流場或球路表格。
- `physics.js`：球面接縫、邊界層與轉捩、分離判準、壓力積分、旋轉受力、三維平均流場及投球軌跡。
- `worker.js`：背景計算四種對照球路、12 個縫線相位的流場與瞬時流線。
- `ball.js`：皮革接縫及 108 組紅色雙縫針；顯示隆起隨模型縫線高度調整。
- `trajectory.js`：3D 軌跡、攝影機操作與顯示用差異放大。

## 操作與比較

主畫面可拖曳旋轉風洞、縮放、近看縫線，以及切換邊界層狀態與分離線。右側「開啟 3D 軌跡（可旋轉）」提供滑鼠拖曳旋轉、滾輪縮放、Ctrl／右鍵平移、手機單指旋轉與雙指縮放平移。另有投手、捕手、側面、俯視、進壘及斜視六種預設視角。

四組軌跡使用相同出手位置、速度與方向：完整模型（旋轉＋縫線）、有旋轉但無縫線效應、無旋轉且無縫線效應、無旋轉但有縫線。旋轉貢獻為第二組減第三組，縫線貢獻為第一組減第二組。

差異放大只影響 3D 圖的位置，以同一前進距離的無旋轉軌跡為基準；進壘數字與實際計算結果保持原值。表格採捕手視角，+x 為捕手右方，單位為英吋（並列公分）。

## 模型範圍

這是含經驗判準的降階教學模型，並非直接求解完整三維 Navier–Stokes 方程的 DNS／LES。縫線可透過轉捩及逆壓區的分離判準改變壓力分布；分離較早或較晚取決於局部邊界層狀態。固定方向積分節點及經驗係數屬於模型常數。

皮革及雙縫針用於辨識幾何與方向，物理核心採簡化接縫曲線，沒有逐針解析局部渦流；煙霧擾動為視覺示意，流線取自模型平均場。結果用於比較參數與機制，不作為實測球路的精準預測。

## 驗證

`node --test tests/baseball-cfd.test.js` 驗證 Blasius／Hiemenz 極限、Thwaites 停滯點、108 組雙縫針的高度、準確的進壘端點，以及差異放大不改動原始結果。

啟動網站的靜態預覽後，執行 `node tests/baseball-cfd.browser.test.cjs`（需開發用 Playwright 與 Chromium）。可用 `BASEBALL_CFD_TEST_URL` 指向預覽或正式網址，`PLAYWRIGHT_CHROMIUM_EXECUTABLE` 指定瀏覽器。涵蓋真實 Worker、即時重新計算、四組球路、六種視角、旋轉／縮放／平移／觸控、320 至 1440px 版面、DPR 圖表尺寸與無 Python／API 請求。
