# 都卜勒・水波實驗

入口：apps/doppler/index.html。純 HTML/CSS/Canvas/JavaScript，可直接提供靜態頁面。

以教師提供的透明片水波投影片為參考，基本操作是讓學生親手排列各片圓形波：預設提供半徑5、4、3、2、1m的五個圓圈，外加半徑0的當下波源位置，五圈整齊放在旁邊的圓片盤，平板與手機版置於水面上方；波源小鴨採俯視外觀，預設在原點且可獨立拖曳。圓片盤只顯示圈號，不再顯示5λ、4λ等大小標示。圓片盤使用相同比例的縮圖，拖入水面後按真實尺度繪製；也可選片後點水面，或按Enter放在中央。每一片均可抓圓心或圓周獨立拖曳，半徑固定；重疊時用選單選片，方向鍵微調，Shift更細，支援復原上一步與收回所有圓圈；收回時保留水面上的小鴨及其位置。

選擇靜止及¼、½、¾波速只改題目條件，不幫學生排列。用方格、兩點量測或小鴨完成圖形與回答後下載PNG。四題均先要求學生自己組圖，再推理發波時間、波間距與接收頻率。圓心、模型參數、各題回答與選填姓名只保存於本機瀏覽器，不傳送到伺服器。最多保留六張當次圖片預覽；離開頁面後須使用下載的圖片。

## 模型

手動模式僅固定每圈5秒時的半徑，圓心與當下波源位置均由學生自由決定，允許不正確的嘗試。拖曳保留抓取位置相對圓心的偏移，不會將圓周突然吸到游標；畫布上方有「啟用磁吸對齊小格」勾選，預設圓心吸附到¼波長的小格交點，開關選擇保存在本機，邊界也限制在完整圓圈可見的格點，取消勾選可自由拖曳。方向鍵移動¼波長，Shift加方向鍵移動1/20波長。輸入x/y座標可精確設定選定圓片，數值輸入不受拖曳吸附影響；超出完整圓圈可見範圍時拒絕，避免暗中改成別的座標。另有移到原點(0,0)按鈕。畫布即時顯示選定圓心座標，輸入、吸附和原點定位皆支援復原與本機保存。

進階區可勾選自動模擬比對，從同樣5秒時刻開始；取消勾選還原手動作品。自動模式以下列等速波源方程建立波前；手動播放另以學生自己排列的波前幾何計算接收，不將任意排列改成等速波源的標準答案。

手動播放：勾選「放置A、B兩隻小鴨」後顯示「播放我的排列」、暫停／繼續、回到原排列與呱聲勾選。只播放已放入水面的非零半徑圓圈；當下波源小鴨是位置標記，不推測未來發波。每圈固定學生給定的圓心，其半徑隨播放經過時間τ增加為r+cτ。小鴨固定於觀察點，抵達時間為τ=(圓心到鴨子的距離−原半徑)/c；負值表示播放前已越過，不計為新的接收。恰好接觸的τ=0算一次；任意排列的接觸順序依實際抵達時間排序，包含同時抵達，避免用標準都卜勒公式替代學生作品。

每隻鴨顯示播放後收到的次數和最近兩次間隔。抵達事件觸發260ms金色光圈、畫布「呱！」及計次卡閃光；Web Audio合成260ms呱聲，放寬濾波頻帶、提高包絡音量，輸出加壓縮器避免多圈同時接觸時爆音，A/B使用同樣的音色與音高，讓呼叫節奏表示接收頻率。僅按播放、試聽或勾選聲音時初始化音訊，不自動發聲。「試聽呱聲」直接播放並開啟聲音勾選，不啟動波前或改變接收次數；啟用失敗時在聲音控制旁顯示提示，不默默取消勾選。靜音及暫停會停止當下叫聲，重新播放重置計次；每個抵達事件只發聲一次。當最後一個可抵達事件完成後停止。五圈有限波前的最終總次數可相同，應比較抵達間隔或同一段播放時間的次數。

播放資料與原作品分離，圓片不被動畫改寫；回到排列完全恢復原圖。拖曳圓片／觀察鴨、改座標或改物理設定會退出播放並清空接收紀錄；暫停後可量測或下載當下波形。播放時的PNG標示經過時間、A/B次數及間隔。手動排列任意圖形仍可能不是等速波源在過去5秒的物理解，這屬學生可觀察與修正的嘗試。

自動模式採靜止且均勻的介質，理想無色散圓形波前；忽略反射、衰減及干涉振幅。用於教學幾何，不聲稱模擬完整水面流體。波源做等速水平運動，速度絕對值小於波速。基本 c=1 m/s、f=1次/s。t=0 發第一圈，t=n/f 發第 n 圈。

每圈圓心為發出時的波源位置 x_n=v源 n/f，半徑 r_n=c(t−n/f)。發出的圓圈不隨波源平移。5 秒有五圈非零半徑圓及第六個剛發出的點。中心點代表歷史發波位置；黃色圖示是波源當下位置。

觀察者靜止在 (x_o,y_o)，第 n 圈抵達時間為 n/f + hypot(x_o−x_n,y_o)/c。拖曳小鴨會重新建構它在該位置全程靜止的實驗，並非模擬小鴨的移動軌跡。可正確處理離軸觀察與波源越過觀察者後的波。抵達次數包含0到當下的端點；相鄰兩次實際抵達間隔的倒數才是該間隔的接收頻率。不用穩態頻率乘總播放時間代替波數。

同軸、波源尚未越過觀察者時，前方 λ=(c−v源)/f、後方 λ=(c+v源)/f，接收頻率各為 f/(1∓v源/c)。第一次到達存在傳播延遲，因此從開始發波起算10秒的次數，與穩定接收後長10秒的半開區間次數不一定相同。

物理參考：[OpenStax University Physics 17.7](https://openstax.org/books/university-physics-volume-1/pages/17-7-the-doppler-effect)。

## 顯示與作答

預設手動5秒透明片，標記時間與小鴨關閉，方格與圓心開啟。自動模式時間控制預設隱藏，自動比對的勾選放在收起的進階區。自動播放到10秒停下；切換速度保留時刻以便比較。

進階波速或頻率改變後，更新各片半徑並保留對應圓片的圓心，新圓片放入圓片盤。當下波源是獨立的零半徑標記；即使5秒不是發波時刻（例如每2秒一次），仍提供此標記，區別於當時最近發出的非零半徑波。瀏覽器保存每片是否已放入水面；舊版未改動的打散預設轉入圓片盤，學生已修改的舊作品則保留。

投影保持x、y等比例；方格操作區使用整行頁面寬度，設定移到下方；手動畫布的高度等於可用寬度，自動模擬保留原有高度設定。手動水面固定為正方形，基本範圍為x/y各±6.25m，五圈波形保留必要的排列餘裕；移除52px/m上限，水面變寬時格子與圓圈一起放大。1050px以下圓片盤移至上方，將整行寬度留給方格；圓心使用十字標記、編號移到旁邊以便對齊格線，自動模式5秒前視野固定、之後隨最大波半徑擴大。每大格固定代表靜止波源的基準波長λ=c/f，每大格分成4小格；基本設定即大格1m、小格0.25m。修改進階波速或頻率後，方格也更新；移動波源前、後方的不同波間距以同一基準比較。窄螢幕仍保留波長大格，僅減少刻度數字；若進階極端設定使小格不足1px，省略小格線以免遮蔽波形。兩點量測使用物理坐標，匯出尺寸不影響距離。波源與觀察者小鴨均為俯視圖，背部標點顯示精確坐標。小鴨圖案只作辨識，以其坐標點判定接收。

手動排列不提供縮放或平移相機；圓心位置不影響投影尺度，避免拖曳時格子縮放。基本五圈在整個水面保持完整可見：768/1024px平板每大格約58/78px，每小格約14/20px，1440px桌面每大格約97px。只有修改進階波速或頻率才依最大半徑更新必要視野。輸入和拖曳均限制在完整圓圈可見範圍，先前儲存的坐標不會被無聲修改。

PNG依完整操作區同比例縮放到1200px寬，保留靠近邊界的完整圓圈，繪製當時排列、設定、小鴨坐標、方格尺度、量測與題目／回答，明確標示「學生手動組合」或「自動模擬」。不使用自動解替換學生作品。只有自動模式且紀錄面板開啟時才加入接收數據。另可只下載水波圖；下載前暫停，禁用儲存時提示先下載。
