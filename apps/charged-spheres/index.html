01 / 球殼定理

球外的場，等同球心電荷

均勻帶電球在球外的電場，精確等於把其總電荷放在球心。這是球對稱分布的性質，球很大或很靠近都不會改變，只要觀察點仍在球外。

02 / 合力加總

不是每一小塊都受一樣的力

A 球在 B 球內各位置的電場不同。必須加總整顆 B 球的 ρ₂ E₁ dV，連同方向一起算；兩球不重疊時，結果精確等於 kQ₁Q₂ / d²。

03 / 距離的意義

靠近不會自動讓公式失效

本模型不需要 d 遠大於 R。若電荷分布不再球對稱，通常才需要用遠距離的質點近似。本頁討論靜電作用，不是電磁輻射的近場／遠場分區。

用間隙 g 或球心距 d 代入，結果會一樣嗎？

看解釋 ＋

應該使用球心距 d = 2R + g。球面快要接觸時 g 接近零，但球心距仍接近 2R，所以均勻球的合力保持有限，不會因為間隙趨近零而發散。

為什麼精確相等？模型、推導與參考資料

模型是假設真空中兩顆固定、均勻帶電的實心球，各球的體電荷密度為 ρ = 3Q / (4πR³)，不允許電荷移動或介電極化。球心距 d 大於兩球半徑和，兩球不接觸。本頁用共同半徑控制；等效公式同樣適用於半徑不同、各自保持球對稱且不重疊的兩球。

球殼定理先把 A 球在球外的位勢等效為球心點電荷。將這個位勢對 B 球的球對稱電荷分布積分，再用一次球殼定理，可得交互作用能 U = kQ₁Q₂ / d。因此，B 球朝遠離 A 的方向所受合力為 F = −dU / dd = kQ₁Q₂ / d²。這並不假設整個雙球系統的場具有球對稱。

主要數值由兩球各自的三維立方網格求得：取格心位於球內的小格，各分配 Q / N 的點電荷，逐對套用向量庫倫公式。格心與球面邊界近似破壞了連續球的精確球對稱，有限格數的偏差是真正算出的數值誤差。所有間距的數值曲線都重新逐對演算，沒有直接抄解析公式。

獨立驗證用 16 階 Gauss–Legendre 體積分，將 B 球沿兩球連線切層，再對每個切層的圓盤積分 A 球的局部電場；橫向合力由對稱性抵消。連續球的精確物理結果始終為球心公式。Q = 0 時，本均勻體電荷模型的密度也為零，不包含感應電荷。
