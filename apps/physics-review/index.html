UNIT 01

物理科學史與SI基本單位

核心觀念整理

物理科學的發展是由無數科學家的觀察與實驗累積而成。2019年起，國際度量衡大會全面改以「自然物理常數」來重新定義國際單位制 (SI)，使其不再依賴實物標準。

Q1. 下列物理量單位，何者為國際度量衡大會制定之「SI 基本單位」？

A
牛頓 (N)
B
焦耳 (J)
C
庫侖 (C)
D
克耳文 (K)
正確答案：D
解析：國際單位制 (SI) 的七大基本單位包括：長度（公尺 m）、質量（公斤 kg）、時間（秒 s）、電流（安培 A）、溫度（克耳文 K）、物質量（莫耳 mol）、光強度（燭光 cd）。牛頓、焦耳與庫侖均為導出單位。

Q2. 下列哪一組物理量的單位，在國際單位制 (SI) 中均為「導出單位」？

A
焦耳、克耳文、安培
B
牛頓、庫侖、瓦特
C
莫耳、公尺、秒
D
帕斯卡、公斤、燭光
正確答案：B
解析：(B) 選項中：牛頓（力和加速度，$\text{kg}\cdot\text{m/s}^2$）、庫侖（電荷量，$A\cdot s$）、瓦特（功率，$\text{kg}\cdot\text{m}^2/\text{s}^3$）皆可由基本單位導出，故全部都是導出單位。克耳文、安培、莫耳、公尺、秒、公斤、燭光均是基本單位。

A
法拉第 (Faraday)
B
安培 (Ampère)
C
赫茲 (Hertz)
D
厄斯特 (Oersted)

UNIT 02

物質的組成與四大基本交互作用

核心觀念整理

宇宙中所有物質皆由基本粒子所構成，並透過四種基本交互作用力彼此連結。夸克為分數電荷，而日常接觸力皆為電磁力的微觀表現。

夸克模型

  • 質子 ($p$)：由兩個上夸克與一個下夸克組成 ($uud$)。電荷：$+2/3 + 2/3 - 1/3 = +1e$。
  • 中子 ($n$)：由一個上夸克與兩個下夸克組成 ($udd$)。電荷：$+2/3 - 1/3 - 1/3 = 0e$。

基本粒子發展史

基本粒子 說明 發現相關證據
原子 古希臘便有 Atom 一詞出現，意為不可分割，認為原子是物質的最基本單元。 倍比定律：為道爾吞原子假說提供化學實質支持。
布朗運動：愛因斯坦在物理上證明了微粒隨機運動是由周圍水分子的熱碰撞引起，為原子/分子論提供了直接的物理實驗證據。
電子 湯木生利用陰極射線管實驗，首度發現了比原子還小、帶負電荷的粒子（電子），打破了原子不可分割的觀念。 在電場或磁場中會發生偏轉，且其電荷與質量的比值（荷質比）遠大於任何已知原子離子。
質子 (原子核) 拉塞福進行金箔 $\alpha$ 粒子散射實驗，發現原子中心存在質量集中且帶正電的原子核；隨後透過撞擊實驗發現了質子。 帶正電的 $\alpha$ 粒子撞擊金箔時，有極少數粒子會發生大角度偏折甚至是反彈，意味著原子內部逆向大半為空，而質量集中於帶正電荷的微小中心（原子核）。
中子 查兌克以實驗證實原子核內存在不帶電荷且質量與質子相近的粒子，即為中子。 使用 $\alpha$ 粒子轟擊鈹核產生極強穿透性且不帶電的射線，該射線撞擊石蠟時能打出高能質子。
夸克 蓋爾曼提出夸克假說，科學家後續利用深度非彈性電子散射實驗探測質子與中子，證實其內部有更基本的組成分子（夸克）。 高能電子射向質子與中子的結構散射數據分析，顯示其內部存在電荷分布的點狀結構。

日常接觸力（拉力、摩擦力、正向力、繩子張力、彈簧彈力）雖然名稱相異，但其本質全部屬於微觀下的電磁交互作用！另外注意，強交互作用和弱交互作用為短程力，在原子核尺度外強度便降為零，因此日常生活中感受不到。

UNIT 03

運動學與牛頓力學

核心觀念整理

運動學描述物體的位置如何隨時間改變；牛頓力學則探討改變物體運動狀態的因素——也就是「力」。

常見運動學物理量

物理量 常用代號 說明 定義關係式
位置 $x$ 描述物體在空間中的坐標點位置。 -
位移 $\Delta x$ 位置的變化量，屬於向量（具有大小與方向），僅與起點 and 終點有關。 $\Delta x = x_{\text{末}} - x_{\text{初}}$
路徑長 $L$ 物體實際運動軌跡的總長度，屬於標量（僅具大小，無方向）。 -
速度 $v$ 單位時間內的位置變化（位移），屬於向量，方向與位移方向相同。 $v = \frac{\Delta x}{\Delta t}$
速率 $v_s$ 單位時間內的路徑長度，屬於標量，常用於描述運動的快慢。 $v_s = \frac{L}{\Delta t}$
加速度 $a$ 單位時間內的速度變化量，屬於向量，方向與速度變化方向相同。 $a = \frac{\Delta v}{\Delta t}$

等加速度運動三大公式

當加速度為定值時，各物理量滿足以下關係（以初位置為原點）：

  • 末速度與時間：$v = v_0 + at$
  • 位移與時間：$\Delta x = v_0 t + \frac{1}{2}at^2$
  • 末速度與位移：$v^2 = v_0^2 + 2a\Delta x$

圖形斜率與面積的意義

  • 位置-時間圖 ($x-t$)：切線斜率代表「瞬時速度」。
  • 速度-時間圖 ($v-t$)：切線斜率代表「瞬時加速度」；與時間軸所夾面積代表「位移」。
  • 加速度-時間圖 ($a-t$)：與時間軸所夾面積代表「速度變化量 ($\Delta v$)」。
學測考點陷阱！

1. 在 $v-t$ 圖中，只要圖形都在時間軸的上方，代表速度皆為正值，物體持續前進，沒有折返（即使斜率向下也是在前進，只是在減速）。
2. 靜摩擦力的大小由合力狀態決定（$f_s = F_{\text{平行}}$），與正向力無關！只有最大靜摩擦力（$f_{s,\text{max}} = \mu_s N$）和動摩擦力（$f_k = \mu_k N$）才跟正向力 $N$成正比。

天體運動學說演進

科學家 宇宙天體模型 運動現象之合理解釋方式

電磁學與電磁感應

核心觀念整理

歷史上厄斯特發現電流的磁效應，開啟電與磁的連結；法拉第發現電磁感應，實現「磁生電」；馬克士威則將電磁學大一統並預言電磁波。

核心效應對稱性

  • 電流磁效應 (電生磁)：載流導線產生環狀磁場。方向遵循安培右手定則。
  • 電磁感應 (磁生電)：封閉線圈內「磁通量改變」產生感應電流。方向由冷次定律決定（感應磁場必反抗外在磁場變化，其本質為能量守恆）。

法拉第定律公式

感應電動勢（電壓）與磁通量變化率成正比：

$$\mathcal{E} = -N \frac{\Delta \Phi_B}{\Delta t}$$

電磁波譜（頻率高到低，亦即能量大到小、波長短到長）

$$\gamma \text{ 射線} \rightarrow X \text{ 射線} \rightarrow \text{紫外線} \rightarrow \text{可見光} \rightarrow \text{紅外線} \rightarrow \text{微波} \rightarrow \text{無線電波}$$

注意：所有電磁波在真空中傳播速度相同，皆為光速 $c \approx 3 \times 10^8 \text{ m/s}$。滿足關係式 $c = f\lambda$。

UNIT 05

波動與都卜勒效應

核心觀念整理

波動傳遞能量但不傳遞介質。都卜勒效應是指波源與觀測者有相對運動時，觀測頻率發生變化的現象。

波動的基本公式

$$v = f\lambda$$
  • 頻率 $f$：由波源決定。波在折射進入不同介質時，頻率維持不變。
  • 波速 $v$：由介質決定。例如光從空氣入水，波速變慢；聲波從空氣入水，波速變快。
  • 波長 $\lambda$：依介質及頻率共同調節變動。

都卜勒效應機制

  • 相對接近：觀測波長被壓縮，頻率變高（聲音音調變尖銳，光譜藍移）。
  • 相對遠離：觀測波長被拉長，頻率變低（聲音音調變低沉，光譜紅移）。
  • 注意：波源在介質中傳播的波速和波源發出的真實頻率並未改變！

兩者波速都變快，皆偏離法線
C
聲波速度變快偏離法線，光波速度變慢偏向法線
D
聲波速度變慢偏向法線，光波速度變快偏離法線
正確答案：C
解析：聲波是力學波，在固體與液體中的波速大於空氣，入水波速變快，因此折射角大於入射角，偏離法線；光波在水中的波速變慢（折射率 $n_{\text{水}}\approx 1.33 > n_{\text{空氣}}$），因此折射角小於入射角，偏向法線。

UNIT 06

功、能量與核能

核心觀念整理

功是能量轉移的量度。核反應中微小的質量虧損能釋放龐大的能量，本質是由愛因斯坦質能互換公式主導。

功的定義

$$W = Fd\cos\theta$$
  • 力與位移垂直時，此力不作功（例如向心力不作功、提水桶等速水平走路不作功）。
  • 力與位移夾銳角作正功，夾鈍角作負功。

其中 $c = 3 \times 10^8 \text{ m/s}$。當損失 $1\text{ g}$ 的質量，可轉化為 $9 \times 10^{13}\text{ 焦耳}$ 的能量！

Q1. 根據愛因斯坦質能互換公式 $E=\Delta m c^2$，在一核反應過程中，若損失了 $1\text{ g}$ 的質量，將會釋放出多少焦耳的能量？

A
$3\times 10^5$
B
$3\times 10^8$
C
$9\times 10^{10}$
D
$9\times 10^{13}$
正確答案：D
解析：公式中質量的單位必須為「公斤 (kg)」。$1\text{ g} = 10^{-3}\text{ kg}$，光速 $c = 3 \times 10^8\text{ m/s}$。帶入公式可得：$E = 10^{-3} \times (3 \times 10^8)^2 = 10^{-3} \times 9 \times 10^{16} = 9 \times 10^{13}\text{ J}$。

Q2. 下列關於「功」與「運動狀態」的敘述，何者正確？

A
當人手提重物在水平地面上等速度走動時，人手對重物所作之功為正功
B
人造衛星繞地球作圓周運動時，重力對衛星所作的功為零
C
滑動摩擦力對運動中的物體必定作正功，以維持其前進
D
物體斜向拋出後，在上昇段重力對其作正功
正確答案：B
解析：(B) 正確。因為人造衛星作圓周運動時，其所受的重力（向心力）方向恆與速度（瞬時位移）方向垂直（$\theta = 90^\circ$），由 $W = Fd\cos 90^\circ = 0$，可知重力不作功。手提重物水平走、重力垂直水平位移，功亦為零。

UNIT 07

量子論與近代物理

核心觀念整理

近代物理的兩大基石是「量子論」與「相對論」。近代物理揭示了微觀世界粒子與波動共存的本質。

量子假說與光量子說

  • 普朗克量子假說：黑體輻射能量並非連續，而是以量子為最小單位。光子能量公式：$E = hf$
  • 愛因斯坦光電效應：光子與電子一對一碰撞。光的能量一部分克服束縛（功函數 $W$），其餘轉為電子動能：
    • $$hf = W + K_{\text{max}}$$

操縱變因 (變大) 控制變因 截止電壓 $V_s$ (動能) 光電流 $I$ 與古典物理之衝突
光頻率 $f < f_0$ 無電子噴出 無電流 古典物理認為：只要入射光強度足夠強或照射時間足夠久，應能激發出電子。
光頻率 $f \ge f_0$ 立即產生 立即產生 古典物理認為：若為弱光照射，電子需在表面累積能量，應有明顯的時間延遲（數分鐘或數小時）。
光頻率 強度、材質 變大 ($V_s \propto f$) 不變 古典物理認為：波的能量只與其強度（振幅）有關，與頻率無關，故不應存在特定的「底限頻率」。
光強度 頻率、材質 不變 變大 ($I \propto$ 強度) 古典物理認為：光越強代表能量越高，激發出的電子最大初動能與截止電壓 $V_s$ 應隨光強增加而變大。
金屬材質 頻率、強度 隨 $W$ 改變 不變 古典物理無法解釋為何不同材質的金屬會有各自特定的能量門檻（功函數 $W$）。

戴維森與革末的電子繞射實驗

Q2. 關於愛因斯坦對「光電效應」的解釋，下列敘述何者符合其光量子假說？

A
只要照射光強度（亮度）足夠強，任何頻率的光均能激發出電子
B
入射光子與電子為一對一碰撞。頻率低於底限頻率時，無論多亮或照多久皆無法噴出電子
C
激發出的光電子最大初動能與入射光強度成正比
D
弱光照射時需要累積能量，因此光電子會產生明顯時間延遲
正確答案：B
解析：愛因斯坦提出光子說，認為一個光子只與一個電子作用。光子能量為 $E = hf$。如果頻率低於底限頻率 $f_0$（光子能量小於金屬功函數 $W$），則不論光多強都無法打出電子。若大於 $f_0$，即使光微弱也會瞬間打出。

D
