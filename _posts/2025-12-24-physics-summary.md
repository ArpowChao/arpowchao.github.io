## SI制單位
{: #si-units .section-header}

SI制單位之間的轉換係數都是1，因此使用SI制可以簡化數學轉化。

### **基本單位**
這是基於2019年由國際度量衡大會確定的新的定義方式，這種定義方法使得這些單位不再依賴於實物標準或實驗測量，而是使用不隨時間改變的自然常數。

| 物理量 | SI單位 | 定義方法                                                                                                      |
| :----: | :----: | :------------------------------------------------------------------------------------------------------------ |
|  長度  |  $m$   | 以光在真空中 1/299,792,458 秒內行進的距離來定義                                                               |
|  質量  |  $kg$  | 現在是基於普朗克常數 $h$ 的值                                                                                 |
|  時間  |  $s$   | 基於銫-133原子在兩個超精細能階間的 9,192,631,770 次輻射周期                                                   |
|  電流  |  $A$   | 現在是基本電量 $e$ 的值                                                                                       |
|  溫度  |  $K$   | 現在是基於波茲曼常數 $k_B$ 的值                                                                               |
| 光強度 |  $Cd$  | 頻率 $540\times 10^{12}$Hz 之光源發出之單頻輻射，在一定方向每立弳之輻射通量為 $\frac {1}{683}$ 瓦特之發光強度 |
| 物質量 | $mol$  | 現在是基於亞佛加厥常數 $N_A$ 的值                                                                             |

> 從拉塞福開始，科學家基本都是透過**散射實驗**來探究基本粒子。

#### **夸克模型與強子**
* **夸克的電荷**：夸克帶有分數電荷。
  * 上夸克 ($u$)：帶有 $+\frac{2}{3}e$ 的電荷。
  * 下夸克 ($d$)：帶有 $-\frac{1}{3}e$ 的電荷。
* **強子的組成**：
  * **質子 ($p$)**：由兩個上夸克與一個下夸克組成（$uud$），總電量為 $+\frac{2}{3}e + \frac{2}{3}e - \frac{1}{3}e = +1e$。
  * **中子 ($n$)**：由一個上夸克與兩個下夸克組成（$udd$），總電量為 $+\frac{2}{3}e - \frac{1}{3}e - \frac{1}{3}e = 0$。

#### **基本粒子分類（標準模型簡化版）**
目前物理學認為無法再分割的基本粒子主要分為兩大類：
1. **費米子 (Fermions)** — 構成物質：
   * **夸克 (Quarks)**：包含上夸克 ($u$)、下夸克 ($d$) 等六種。受強交互作用束縛，無法單獨存在（夸克禁閉）。
   * **輕子 (Leptons)**：包含電子 ($e^-$)、微中子 ($\nu$) 等六種。不受強交互作用影響。
2. **玻色子 (Bosons)** — 傳遞交互作用：
   * **光子 ($\gamma$)**：傳遞電磁交互作用。
   * **膠子 ($g$)**：傳遞強交互作用。
   * **弱玻色子 ($W^\pm, Z^0$)**：傳遞弱交互作用。

#### **現代天文發現：暗物質與暗能量**
* **一般物質**：我們看得見的原子、發光恆星等，僅占宇宙總能量與質量的約 **5%**。
* **暗物質 (Dark Matter)**：
  * **證據**：觀測星系外圍恆星自轉速度過快（星系自轉曲線異常）、重力透鏡效應。
  * **性質**：具有質量與重力作用，但不與光（電磁波）發生交互作用，因此看不見。約占宇宙的 **27%**。
* **暗能量 (Dark Energy)**：
  * **證據**：觀測遠方 Ia 型超新星，發現宇宙正在**加速膨脹**。
  * **性質**：充斥於空間中、產生排斥性重力效應的未知能量形式。約占宇宙的 **68%**。

## 運動學
{: #kinematics .section-header}

### **常見運動學物理量**

| 物理量 |  常用代號  | 說明                   | 關係式                                   |
| :----: | :--------: | :--------------------- | :--------------------------------------- |
|  位置  |    $x$     | 物體的所在之處         |                                          |
|  位移  | $\Delta x$ | 位置變化               | $\Delta x = x_{\text{末}}-x_{\text{初}}$ |
| 路徑長 |    $L$     | 實際走的軌跡長度       |                                          |
|  速度  |    $v$     | 每單位時間內的位置變化 | $v = \frac{\Delta x}{\Delta t}$          |
|  速率  |   $v_s$    | 每單位時間內的路徑長度 | $v_s = \frac{L}{\Delta t}$               |
| 加速度 |    $a$     | 每單位時間內的速度變化 | $a = \frac{\Delta v}{\Delta t}$          |

#### **等加速度運動三大公式**
若物體作等加速度運動（$a = \text{常數}$），其運動狀態滿足以下關係式：
1. **速度公式**：$v = v_0 + at$ （無位移資訊時使用）
2. **位移公式**：$\Delta x = v_0 t + \frac{1}{2}at^2$ （無末速度資訊時使用）
3. **平方公式**：$v^2 = v_0^2 + 2a\Delta x$ （無時間資訊時使用）
* **平均速度**：$\bar{v} = \frac{v_0 + v}{2} = \frac{\Delta x}{t}$

#### **運動學圖形分析 (x-t, v-t, a-t)**
* **位置-時間圖 ($x-t$)**：
  * **斜率**：割線斜率代表「平均速度」，切線斜率代表「瞬時速度」。
  * **圖形**：水平線代表靜止；斜直線代表等速度運動；曲線代表變速度（有加速度）運動。
* **速度-時間圖 ($v-t$)**：
  * **斜率**：切線斜率代表「瞬時加速度」。
  * **面積**：圖形與時間軸圍成的面積代表「位移」（時間軸上方面積為正，下方面積為負；面積絕對值之和代表路徑長）。
* **加速度-時間圖 ($a-t$)**：
  * **面積**：圖形與時間軸圍成的面積代表「速度變化量 ($\Delta v$)」。

#### **摩擦力概念總整理**
* **靜摩擦力 ($f_s$)**：物體受外力但仍保持靜止。大小隨外力而變，恆滿足 $f_s = F_{\text{平行}}$（作用力與反作用力原理/合力為零）。
* **最大靜摩擦力 ($f_{s,\text{max}}$)**：物體即將滑動的臨界狀態。公式：$f_{s,\text{max}} = \mu_s N$（與接觸面正向力 $N$ 成正比，$\mu_s$ 為靜摩擦係數）。
* **動摩擦力 ($f_k$)**：物體處於滑動狀態。公式：$f_k = \mu_k N$（通常為定值，且 $\mu_k < \mu_s$，即動摩擦力小於最大靜摩擦力）。

### **自然運動**

#### 天體運動
{: #celestial-motion}
為解釋特殊星體運動現象：**行星逆行**。

| 科學家 |     模型     | 解釋方式                       |
| :----: | :----------: | :----------------------------- |
| 托勒密 |    地心說    | 地球中心，利用本輪與均輪解釋   |
| 哥白尼 |    日心說    | 太陽中心，以相對運動解釋       |
| 克卜勒 | 行星運動定律 | 基於日心說修正，歸納出三大定律 |

##### **克卜勒行星運動三大定律**
1. **第一定律（軌道定律）**：行星繞太陽的軌道為橢圓，太陽位於橢圓的其中一個焦點上。
2. **第二定律（等面積定律）**：行星與太陽的連線在相同時間內掃過的面積相等。
   * 物理意義：近日點距離短速度快，遠日點距離長速度慢。滿足 $r_{\text{近}} v_{\text{近}} = r_{\text{遠}} v_{\text{遠}}$（微觀本質上是角動量守恆）。
3. **第三定律（週期定律）**：所有繞太陽運行的行星，其平均軌道半徑（橢圓半長軸 $R$）的立方與公轉週期（$T$）的平方之比為定值：
   $$\frac{R^3}{T^2} = K$$
   * 注意：常數 $K$ 僅與中心星體（此處為太陽）的質量有關。若中心星體不同（例如衛星繞地球），則 $K$ 值不同。
   
#### 伽利略的慣性
{: #newtonian-mechanics}
思考一：重物掉落 (與輕物綁在一起的矛盾實驗)。
觀察：單擺會回到原高點。
思考二：慣性 (光滑斜面實驗)。
* 結論：若無外力干涉，運動中的物體會一直保持其運動狀態，這是牛頓第一運動定律的前身。

## 電磁學
{: #electromagnetism .section-header}

### **場的概念**
* **電場 (Electric Field)**：電荷周圍存在電場。電力線由正電荷出發，終止於負電荷，電力線上任一點的切線方向即為該點電場方向（正電荷受力方向）。
* **磁場 (Magnetic Field)**：磁鐵或電流周圍存在磁場。磁力線外部由 N 極指向 S 極，內部由 S 極指向 N 極，形成不相交的封閉曲線。

### **電流磁效應**
* **厄斯特**發現：載流導線周圍會產生磁場，首次搭起「電」與「磁」的橋樑。
* **安培右手定則（右手螺旋定則）**：
  * **直導線**：大拇指代表電流方向，彎曲四指代表環狀磁場方向。
  * **環形導線與螺線管**：彎曲四指代表電流方向，大拇指代表中心磁場（磁極 N 極）方向。

### **電磁感應**
* **法拉第電磁感應定律**：穿過線圈的磁通量（磁力線總數）發生變化時，線圈會產生感應電動勢（電壓）：
  $$\mathcal{E} = -N \frac{\Delta \Phi_B}{\Delta t}$$
* **冷次定律**：感應電流的方向總是使其產生的磁場去**反抗（阻礙）**原磁場的變化。
  * 本質：這是**能量守恆定律**在電磁學中的展現，防止能量憑空產生。

### **馬克士威的統合與電磁波**
* **馬克士威方程式**：統合了電學與磁學，指出「變動的電場會產生磁場，變動的磁場也會產生電場」，並預測電磁波的存在，且其傳播速度等同光速（推論出光是一種電磁波）。
* **赫茲實驗**：首次在實驗室利用火花放電產生並接收電磁波，證實了馬克士威的理論。

#### **電磁波譜 (Electromagnetic Spectrum)**
電磁波在真空中傳播速度皆為光速 $c \approx 3 \times 10^8 \text{ m/s}$。依波長由短到長（頻率由高到低）排列：
$$\gamma \text{射線} \rightarrow \text{X 射線} \rightarrow \text{紫外線} \rightarrow \text{可見光 (紫藍青綠黃橙紅)} \rightarrow \text{紅外線} \rightarrow \text{微波} \rightarrow \text{無線電波}$$

## 波動
{: #wave-physics .section-header}

波動定義：波動是**能量的傳遞**，在此過程中介質只在原地附近來回振動，並**不隨波前進**。

### **波動的分類**
* **依是否需要介質**：
  * **力學波**：傳播需要介質，如聲波（空氣）、水波（水）、繩波（繩子）。
  * **非力學波**：不需要介質，可在真空中傳播，如電磁波（光波）。
* **依振動方向與傳播方向關係**：
  * **橫波 (高低波)**：振動方向與傳輸方向垂直，如繩波、電磁波、地震波的 S 波。
  * **縱波 (疏密波)**：振動方向與傳輸方向平行，如聲波、彈簧疏密波、地震波的 P 波。

### **波動的性質**
* **反射**：波遇到界面返回原介質，遵循反射定律（入射角 = 反射角）。波速、波長、頻率皆不變。
* **折射**：波斜向進入不同介質時，因**波速改變**而偏折。遵循司乃耳定律：
  $$\frac{\sin\theta_1}{\sin\theta_2} = \frac{v_1}{v_2} = \frac{\lambda_1}{\lambda_2} = \frac{n_2}{n_1}$$
  * 頻率 $f$ 由波源決定，在折射過程中**保持不變**。
* **干涉**：兩波在空間中相遇重疊，產生加強（相長）或抵消（相消）的現象。
* **繞射**：波繞過障礙物邊緣傳播到其陰影區的現象。當障礙物或狹縫大小**與波長相近或更小**時，繞射現象最明顯。
* **惠更斯原理**：波前上任一點皆可視為一個新的子波源（點波源），發射子波；這些子波在下一時刻的包絡面即形成新的波前。

### **都卜勒效應 (Doppler Effect)**
當波源與觀測者有相對運動時，觀測者所測得的頻率會發生變化：
* **相對接近時**：波長被壓縮，觀測頻率變高（聽到的音調變高、光譜產生**藍移**）。
* **相對遠離時**：波長被拉長，觀測頻率變低（聽到的音調變低、光譜產生**紅移**）。
  * 注意：波源本身發出的頻率和介質中的波速均未改變。
  * 應用：雷達測速、天文膨脹觀測（紅移）。

## 能量
{: #energy .section-header}

### **功 (Work) 與 功率 (Power)**

* **功 (Work)**：能量轉移的描述。若力 $F$ 與位移 $d$ 夾角為 $\theta$，則 $W = Fd\cos\theta$。
  * **正功** ($\theta < 90^\circ$): 物體能量增加。
  * **負功** ($\theta > 90^\circ$): 物體能量減少（如阻力）。
  * **不作功**: $F \perp d$ ($\theta = 90^\circ$) 或無位移時。
* **功率 (Power)**：單位時間內所作的功。$P = \frac{W}{\Delta t}$。
  * 單位：瓦特 (W)，$1\text{ W} = 1\text{ J/s}$。

### **常見的能量類型**

| 能量種類 |         關係式          | 代數說明                           | 說明                                    |
| :------: | :---------------------: | :--------------------------------- | :-------------------------------------- |
|   動能   | $E_k = \frac{1}{2}mv^2$ | $m$: 質量, $v$: 速度               | 物體因運動而具有的能量。                |
| 重力位能 |       $U_g = mgh$       | $g$: 重力加速度, $h$: 距零位面高度 | 物體在重力場中因位置擁有的位能。        |
| 彈性位能 | $U_s = \frac{1}{2}kx^2$ | $k$: 彈性常數, $x$: 形變量         | 彈性體形變時儲存的能量。                |
| 微觀動能 |  $E_{\text{thermal}}$   | 分子平均動能                       | 分子隨機運動的表現，巨觀即為溫度/熱能。 |

### **焦耳實驗與能量守恆**

* **焦耳實驗**：測量機械功與熱量的轉換關係，證明熱是能量的一種形式。
  * **熱功當量**：$1 \text{ cal} \approx 4.186 \text{ J}$。
* **能量守恆定律**：能量不會憑空產生或消失，僅會在不同形式間轉化或由一物體轉移至另一物體。
* **能量危機**：雖然總能量守恆，但能量在使用過程中會由「高品質」（如電能、機械能）退化為「低品質」（如廢熱），導致可用能量減少。

### **質能互換 (Mass-Energy Equivalence)**

* **愛因斯坦公式**：$E = mc^2$。
* **意義**：質量與能量本質相同，可相互轉換。在核分裂或核融合中，質量的虧損 ($\Delta m$) 會轉換成巨大的能量。

### **能量的轉移效率**

| 物理量 |          關係式          | 代數說明                  | 說明                     |
| :----: | :----------------------: | :------------------------ | :----------------------- |
|  功率  | $P = \frac{W}{\Delta t}$ | $W$: 功, $\Delta t$: 時間 | 能量轉換的快慢（時變率） |
| 電功率 |        $P_E = IV$        | $I$: 電流, $V$: 電壓      | 電能轉換的速率           |

## 近代物理
{: #modern-physics .section-header}

### **量子論的誕生 (Birth of Quantum Theory)**

*   **黑體輻射 (Blackbody Radiation)**：古典物理無法解釋的高溫物體輻射強度分佈（紫外災難）。
*   **普朗克假說**：能量不是連續的，而是以「能量包」的形式存在（量子化）。
    *   **能量子公式**：$E = hf$
    *   $h \approx 6.626 \times 10^{-34} \text{ J}\cdot\text{s}$ (普朗克常數)。

### **光的粒子性 (Particle Nature of Light)**

    * 透過逆向電壓（截止電壓 $V_s$）觀測電子最大動能 ($K_{\text{max}} = eV_s$)，透過光電流 $I$ 觀測單位時間噴出的電子數。

| :-------------: | :---------: | :------------------------: | :-------------------------: | :------------------------------------------- |
|   **光頻率**    |  $f < f_0$  |       **無電子噴出**       |         **無電流**          | 古典認為只要光強足夠或照射夠久，應能產生電子 |
|   **光頻率**    | $f \ge f_0$ |        **立即產生**        |        **立即產生**         | 古典認為弱光需累積能量，應有明顯延遲         |
|   **光頻率**    | 強度、材質  | **變大** ($V_s \propto f$) |          **不變**           | 古典認為能量與頻率無關，不應有底限頻率       |
|   **光強度**    | 頻率、材質  |          **不變**          | **變大** ($I \propto$ 強度) | 古典認為光越強能量越高，$V_s$ 應隨強度增加   |
|  **金屬材質**   | 頻率、強度  |      **隨 $W$ 改變**       |          **不變**           | 古典無法解釋材質特定的能量門檻（功函數）     |

</details>

  * **古典危機**：無法解釋為何與光強無關、存在底限頻率 ($f_c$)，且無時間延遲。
  * **愛因斯坦解釋**：提出「光量子說」，認為光是由一顆顆「光子」組成。
  * **能量方程式**：$hf = W + K_{\text{max}}$
    * $W$: 功函數（金屬束縛電子的能量）。
    * $K_{\max}$: 光電子的最大初動能。

### **物質的波動性 (Wave Nature of Matter)**

*   **德布羅意假說 (de Broglie Hypothesis)**：認為不只是光具有波粒二象性，所有物質（如電子）都具有波動性。
    *   **物質波公式**：$\lambda = \frac{h}{p} = \frac{h}{mv}$
*   **實驗證明**：戴維森與革末利用電子束照射鎳晶體，觀察到繞射現象，證實了負電子的波動性。

### **波粒二象性 (Wave-Particle Duality)**

| 特性         | 粒子性                                             | 波動性                   |
| :----------- | :------------------------------------------------- | :----------------------- |
| **表現現象** | 碰撞、光電效應、康普頓效應                         | 干涉、繞射、偏振         |
| **關鍵代數** | 動量 $p$、能量 $E$                                 | 波長 $\lambda$、頻率 $f$ |
| **關聯繫**   | $E = hf$                                           | $p = \frac{h}{\lambda}$  |
| **微觀意義** | 物質波代表「機率波」，即粒子在某空間出現的機率分佈 |                          |

### **原子光譜與能階 (Atomic Spectra & Energy Levels)**

*   **波耳氫原子模型 (Bohr Model)**：
    1. **定態理論**：電子在特定軌道運動時不輻射能量，處於穩定狀態（能階）。
    2. **躍遷理論**：電子在能階間跳動時，須吸收或放出一個光子。
       * $\Delta E = \vert E_2 - E_1 \vert = hf$
    3. **解釋**：完美解釋了氫原子的「不連續」發射光譜（巴耳末系）。
